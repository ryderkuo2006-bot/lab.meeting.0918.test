# Synthetic genome dataset

This directory contains six fictional, short genome-like DNA sequences and their metadata for testing demos, import workflows, and analysis pipelines.

## Files

- `genomes.fasta`: six nucleotide sequences in FASTA format.
- `metadata.csv`: one metadata row per sequence. Join on `genome_id`.

All sequences, organism names, strains, dates, locations, and sample descriptions are synthetic. The sequences are intentionally short test data, not complete biological genomes, and do not represent real biological samples or accessions.
